# Self-hosted fonts for the design-your-own font sets

Used by `src/styles/fonts.css`. Each folder holds the font files and their licence, taken from the official source on 2026-11-06. A file is only downloaded by a browser when a font set that uses it is chosen.

| Family | Used by | Licence | Source |
|---|---|---|---|
| Atkinson Hyperlegible | Studio, Paper, Neon body | SIL OFL 1.1 | Google Fonts (latin subset); licence from github.com/google/fonts `ofl/atkinsonhyperlegible` |
| Bricolage Grotesque | Studio headings | SIL OFL 1.1 | Google Fonts; `ofl/bricolagegrotesque` |
| Encode Sans Semi Condensed | Machined headings | SIL OFL 1.1 (Reserved Font Name "Encode Sans") | UI/UX design library `project/fonts`; `ofl/encodesanssemicondensed` |
| Manrope | Machined body | SIL OFL 1.1 | UI/UX design library; `ofl/manrope` |
| IBM Plex Mono | Machined codes | SIL OFL 1.1 (Reserved Font Name "Plex") | UI/UX design library; `ofl/ibmplexmono` |
| Special Elite | Paper headings and codes | Apache 2.0 | Google Fonts; `apache/specialelite` |
| Caveat | Notebook text fields | SIL OFL 1.1 | Google Fonts; `ofl/caveat` |
| Pixelify Sans | Pixel | SIL OFL 1.1 | Google Fonts; `ofl/pixelifysans` |
| VT323 | Pixel codes | SIL OFL 1.1 | Google Fonts; `ofl/vt323` |
| Orbitron | Neon headings | SIL OFL 1.1 (Reserved Font Name "Orbitron") | Google Fonts; `ofl/orbitron` |

The files are unmodified. JetBrains Mono and Space Grotesk (Teamflow's own fonts) still load from Google Fonts in `index.html`.
