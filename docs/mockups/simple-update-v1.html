Settings → Updates, made simple

One card, one sentence, one button. The page answers “am I up to date?” and offers “Update to vX.Y.Z”. A database backup always runs first, so there is no backup choice on the main card. Everything else moves into a collapsed Advanced section. This assumes the prebuilt releases in docs/INSTALL-PLAN.md. Versions replace commit hashes, and the branch field goes away.

FieldTodayNew

/health{ ok }+ version, so the reconnect overlay knows when the new release is up
