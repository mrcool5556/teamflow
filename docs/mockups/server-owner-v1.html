2 · Server admin → Updates & backups (Backups power)

The backup list

  • The total used and the backup folder sit at the top. Below them is one row per file: date, type (database, uploads or checkpoint), size, then Restore and Delete.
  • The newest database backup has no Delete (the server refuses it). Its row says "newest, kept".
  • Delete asks: "Delete teamflow_2026-11-09_031500.db for good? This can't be undone. It frees 3.1 MB."
  • Two keep-N fields (1–100): database backups (default 10) and upload archives (default 1). They're applied after the next backup. They save on change, with "Saved" next to them.
  • Someone with Updates but not Backups sees the update card only; the backup list and buttons are hidden.
